# System Illustrations

## 1. Use Case Diagram

The Use Case Diagram illustrates the actors and the primary functionalities of the Library Management System. It provides an overview of the interactions between users and the services offered by the system.

![Use Case Diagram](/images/8-Figures/use_case_diagram.jpg)

> **Figure 1.** Use Case Diagram of the Library Management System.



## 2. Entity Relationship Diagram (ERD)

The Entity Relationship Diagram (ERD) illustrates the database structure of the system, including the database tables and the relationships between them. It serves as the foundation for implementing the PostgreSQL database.

![Entity Relationship Diagram](/images/8-Figures/ERD_diagram.jpg)

> **Figure 2.** Entity Relationship Diagram (ERD) of the system.


## 3. Sign In Page

The Sign In page allows new users to register an account before accessing the system. Users are required to provide the necessary information to create an account successfully.

![Sign In Page](/images/8-Figures/signin.png)

> **Figure 3.** Sign In Page.



## 4. Login Page

The Login page authenticates users before granting access to the Library Management System. After successful authentication, users are redirected to the appropriate dashboard based on their assigned roles.

![Login Page](/images/8-Figures/login.png)

> **Figure 4.** Login Page.


## 5. Main Menu

The Main Menu provides quick access to all major modules of the Library Management System, allowing users to navigate efficiently according to their permissions.

![Main Menu](/images/8-Figures/main_menu.png)

> **Figure 5.** Main Menu Interface.


## 6. Librarian Dashboard

The Dashboard presents an overview of important library statistics, including books, readers, borrowing records, and other key information that helps librarians monitor daily operations.

![Dashboard](/images/8-Figures/dashboard_librarian.png)

> **Figure 6.** Librarian Dashboard.


## 7. Book Information Management

The Book Information module enables librarians to view and manage book details, including titles, authors, publishers, categories, quantities, and cover images.

![Book Information](/images/8-Figures/thong_tin_sach.png)

> **Figure 7.** Book Information Management.


## 8. Edit Book Information

This interface allows users to update book information, including book details, categories, publishers, and cover images.

![Edit Book Information](/images/8-Figures/thay_doi_thong_tin_sach.png)

> **Figure 8.** Edit Book Information Interface.


## 9. Borrowing and Returning Management

The Borrowing and Returning module allows librarians to create borrowing records, process book returns, update borrowing status, and manage transactions efficiently.

![Borrow Return Management](/images/8-Figures/quan_ly_muon_tra.png)

> **Figure 9.** Borrowing and Returning Management Interface.


## 10. Borrowing History

The Borrowing History page displays the complete borrowing records of readers, making it easy to review previous transactions and monitor borrowing activities.

![Borrowing History](/images/8-Figures/lich_su_muon.png)

> **Figure 10.** Borrowing History Interface.


## 11. User Account Management

The User Account Management module allows administrators to create, update, manage, and control user accounts and their corresponding permissions.

![User Account Management](/images/8-Figures/quan_ly_acc.png)

> **Figure 11.** User Account Management Interface.


## 12. Fine Management

The Fine Management module enables librarians to manage overdue fines, update fine amounts, and track payment status for library members.

![Fine Management](/images/8-Figures/quan_ly_tien_phat.png)

> **Figure 12.** Fine Management Interface.
