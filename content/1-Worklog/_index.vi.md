Trong thời gian thực tập từ **08/06/2026 đến 14/08/2026**, mình tham gia chương trình **First Cloud AI Journey** do AWS Study Group tổ chức. Do hoàn thành và nộp báo cáo sớm, nội dung nhật ký công việc này tổng hợp toàn bộ quá trình học tập và làm việc tính đến ngày **31/07/2026** (tương ứng với **08 tuần đầu tiên**).

Trong suốt 08 tuần này, mình được học tập và thực hành các dịch vụ nền tảng của Amazon Web Services (AWS), đồng thời áp dụng những kiến thức đã học vào việc phát triển **Website Quản lý thư viện** theo hình thức làm việc nhóm.

Bên cạnh việc hoàn thành các bài học và bài thực hành trong chương trình, nhóm cũng thực hiện đầy đủ quy trình phát triển phần mềm từ khảo sát yêu cầu, xây dựng proposal, phân tích hệ thống, thiết kế, triển khai đến kiểm thử và hoàn thiện sản phẩm.

Nội dung công việc của từng tuần được tóm tắt như sau:

**Tuần 1:** [Khởi tạo tài khoản AWS, cấu hình IAM, Virtual MFA, AWS Budgets, AWS Support; đề xuất và đánh giá các ý tưởng dự án](1.1-week1/)

**Tuần 2:** [Học Data Engineering Immersion Day, phân tích RDBMS vs NoSQL; thống nhất chọn đề tài Website Quản lý thư viện](1.2-week2/)

**Tuần 3:** [Học Amazon RDS, ElastiCache (Redis) và cách lưu trữ media qua S3; phân tích thuộc tính dữ liệu, ràng buộc toàn vẹn và hoàn thiện phần Yêu cầu CSDL cho tài liệu SRS](1.3-week3/)

**Tuần 4:** [Học Advanced PostgreSQL và Data Lake Fundamentals; phân tích thao tác CRUD của hệ thống, hỗ trợ xây dựng Use Case Diagram và hoàn thiện tài liệu Data Dictionary sơ bộ)](1.4-week4/)

**Tuần 5:** [Học AWS KMS, Secrets Manager và Amazon Macie; phân tích thực thể dữ liệu, trực tiếp thiết kế, chuẩn hóa sơ đồ ERD (3NF) và xây dựng tài liệu Database Schema](1.5-week5/)

**Tuần 6:** [Học Advanced PostgreSQL và quy trình di trú CSDL với AWS DMS, SCT; viết SQL DDL Scripts khởi tạo bảng vật lý trên RDS, sinh dữ liệu mẫu (Mock Data) và thống nhất API Data Contracts](1.6-week6/)

**Tuần 7:** [Cấu hình Docker Compose cho PostgreSQL/Redis, thiết lập tự động nạp dữ liệu mẫu; hỗ trợ team Backend đánh Index, tối ưu câu lệnh SQL/ORM và kiểm thử ràng buộc dữ liệu cho các chức năng trong Sprint 1](1.7-week7/)

**Tuần 8:** [Triển khai Database chính thức lên AWS RDS; phối hợp kiểm thử luồng dữ liệu E2E giữa Frontend - Backend - Database, đánh Index tối ưu các truy vấn SQL chậm, thực hiện Backup/Snapshot và hoàn thiện tài liệu ERD/Data Dictionary](1.8-week8/)
