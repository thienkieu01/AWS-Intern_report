### Week 5 Objectives:

* Learn about AWS data security services such as AWS KMS, AWS Secrets Manager, and Amazon Macie.
* Practice data encryption and managing database access credentials.
* Contribute to analyzing and designing the database for the Library Management Website system.
* Complete the ERD and prepare for the database implementation phase.

### Week 5 Achievements:

* **Knowledge gained:**
  * Understood the role of AWS KMS in data encryption and AWS Secrets Manager in securely managing login credentials.
  * Gained knowledge of Amazon Macie and how it helps detect and protect sensitive data on AWS.
  * Gained a deeper understanding of the database design process, from identifying entities and relationships to building the ERD.

* **Contribution to the project:**
  * Participated in analyzing the data entities and relationships in the Library Management Website system.
  * Helped the team design and complete the Entity Relationship Diagram (ERD), while reviewing keys and data constraints to ensure consistency.
  * Helped build the Database Schema documentation, forming the foundation for the database implementation and writing the table creation statements in the following phase.
