During my internship period from **08/06/2026 to 14/08/2026**, I participated in the **First Cloud AI Journey** program organized by AWS Study Group. Due to early report preparation, this worklog summarizes my learning and work progress up to **31/07/2026** (covering the first **8 weeks**).

Throughout these 8 weeks, I learned and practiced foundational Amazon Web Services (AWS) infrastructure while applying this knowledge to develop a **Library Management Website** through team collaboration.

In addition to completing the program's coursework and hands-on labs, the team executed a full software development lifecycle—from requirements gathering and proposal drafting to system analysis, design, implementation, testing, and final product polish.

The summary of weekly tasks is as follows:

**Week 1:** [Create AWS account, configure IAM, Virtual MFA, AWS Budgets, AWS Support; propose and evaluate project ideas](1.1-week1/)

**Week 2:** [Data Engineering Immersion Day, RDBMS vs NoSQL analysis; project selection for Library Management Website](1.2-week2/)

**Week 3:** [Amazon RDS, ElastiCache (Redis), and media storage via S3; data attribute analysis, integrity constraints, and completion of the Database Requirements for the SRS document](1.3-week3/)

**Week 4:** [Advanced PostgreSQL and Data Lake Fundamentals; system CRUD analysis, support in building Use Case Diagrams, and completion of the preliminary Data Dictionary document)](1.4-week4/)

**Week 5:** [AWS KMS, Secrets Manager, and Amazon Macie; Data entity analysis, direct design, normalization of ERD (3NF) diagram and building Database Schema documentation](1.5-week5/)

**Week 6:** [Learn Advanced PostgreSQL and database migration process with AWS DMS, SCT; write SQL DDL Scripts to initialize physical tables on RDS, generate mock data and standardize API Data Contracts](1.6-week6/)

**Week 7:** [Configure Docker Compose for PostgreSQL/Redis, set up automatic mock data loading; support Backend team in indexing, optimizing SQL/ORM statements and testing data constraints for functions in Sprint 1](1.7-week7/)

**Week 8:** [Deploy the official database to AWS RDS; Coordinate E2E data flow testing between Frontend - Backend - Database, optimize indexing for slow SQL queries, perform backups/snaps, and finalize ERD/Data Dictionary documentation](1.8-week8/)
