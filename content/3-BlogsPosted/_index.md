### [Blog 1 - AUTOMATING DATA MANAGEMENT: BUILDING A COMPREHENSIVE BACKUP & RESTORE SYSTEM ON AWS](3.1-Blog1/)
This blog introduces how to build an automated **Backup & Restore** solution on AWS by integrating **AWS Backup, Amazon SNS, AWS Lambda, and Amazon EC2**. It focuses on deploying infrastructure using **AWS CloudFormation**, configuring tag-based backup plans, automatically validating recovery after each backup, and optimizing costs by cleaning up temporary restored resources, thereby improving system availability and data protection.

### [Blog 2 - AMAZON DYNAMODB – AWS NOSQL DATABASE SERVICE FOR MODERN APPLICATIONS](3.2-Blog2/)
This blog shares my learning experience while exploring **Amazon DynamoDB**. It highlights DynamoDB's key features, including its **NoSQL** data model, **fully managed** architecture, automatic scalability, high performance with single-digit millisecond latency, and pay-as-you-go pricing model. The article also discusses DynamoDB's data modeling approach and its integration with other AWS services such as **IAM, Amazon CloudWatch, and AWS Backup** when building modern cloud applications.

### [Blog 3 - AWS KMS – WHAT I LEARNED ABOUT AWS KEY MANAGEMENT SERVICE](3.3-Blog3/)
This blog shares my understanding of **AWS Key Management Service (AWS KMS)** after studying the service and completing a hands-on lab on **Amazon S3** encryption. It explains key management concepts, the differences between **Encryption in Transit** and **Encryption at Rest**, how **Customer Master Keys (CMKs)** and **Data Keys** work together, and demonstrates how **AWS KMS**, **IAM**, **Amazon S3**, and **AWS CloudTrail** can be integrated to build a secure and well-controlled data protection solution.
